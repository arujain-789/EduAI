# 📘 EDUAI | AI-Powered Exam Evaluation System

EDUAI is an AI-driven academic automation platform designed to transform traditional manual exam evaluation into a faster, scalable, and intelligent workflow using OCR, image preprocessing, and cloud-integrated automation.

Built to reduce teacher workload and improve evaluation efficiency, EDUAI processes handwritten answer sheets with high accuracy while significantly cutting grading time.

---

## 🚀 Problem Statement

Manual exam evaluation is time-consuming, repetitive, and inefficient, especially when handling large volumes of handwritten answer sheets.

Traditional grading workflows:
- Consume significant teacher time  
- Increase chances of human error  
- Slow academic processing  
- Lack scalability  

EDUAI solves this by automating answer-sheet digitization and evaluation through OCR-powered academic workflows.

---

## 💡 Solution Overview

EDUAI uses computer vision and OCR automation to process handwritten exam papers, extract responses, and streamline grading workflows.

### Key Impact:
- ⏱️ Reduced grading effort by **80%** (45 min → 9 min)  
- 📄 Processed **500+ handwritten papers**  
- 🎯 Achieved **92% OCR accuracy**  
- 👨‍🏫 Enabled single-teacher evaluation of full class sets in under 15 minutes
